Consulta de Empresas por CNPJ

Aplicação web desenvolvida para consultar informações cadastrais de empresas brasileiras a partir do CNPJ, utilizando a BrasilAPI como fonte pública de dados.

Objetivo

O projeto foi criado para demonstrar, de forma prática, como uma página web pode buscar informações externas, organizar os resultados consultados e apresentar detalhes relevantes em uma interface simples e funcional.

Solução

A aplicação permite informar um CNPJ sem máscara, consultar os dados da empresa, manter uma lista das empresas pesquisadas e abrir um painel com informações completas de cada registro.

Recursos

  • Consulta de empresas por CNPJ
  • Lista de empresas já carregadas
  • Filtro para localizar consultas anteriores
  • Painel de detalhes com informações cadastrais

Tecnologias

  • HTML5
  • CSS3
  • JavaScript
  • BrasilAPI

Aprendizados

Este trabalho reforçou conceitos de integração com API pública, tratamento de dados recebidos, atualização dinâmica da interface e organização da experiência do usuário em uma aplicação de consulta.
