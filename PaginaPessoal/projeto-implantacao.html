Sistema de Gestão Pessoal (SGP)

Aplicação web desenvolvida para auxiliar no gerenciamento de despesas pessoais, reunindo autenticação de usuários, controle por categorias, filtros de pesquisa, indicadores financeiros e gráficos interativos.

Objetivo

O projeto foi desenvolvido para aplicar, de forma prática, conhecimentos de Frontend e Backend. A solução permite cadastrar, editar, excluir e visualizar despesas pessoais em uma interface organizada e intuitiva.

Solução

O sistema oferece autenticação com JWT, gerenciamento de categorias e despesas, dashboard com indicadores financeiros, filtros de pesquisa, gráfico de distribuição por categoria e layout responsivo.

Recursos

  • Cadastro e autenticação de usuários
  • Controle de despesas pessoais
  • Gerenciamento de categorias
  • Dashboard com indicadores financeiros
  • Gráfico de despesas por categoria
  • Filtros por categoria, status, período e valores
  • Últimas despesas cadastradas
  • Interface responsiva

Tecnologias

  • React, React Router DOM, Axios e Context API
  • Bootstrap 5 e Recharts
  • Node.js, Express e Sequelize
  • MySQL, JWT, bcrypt e dotenv

Arquitetura

O projeto segue o padrão MVC, separando responsabilidades entre modelos, controladores, rotas e componentes da interface. A comunicação entre Frontend e Backend ocorre por meio de uma API REST.

Aprendizados

O desenvolvimento consolidou conhecimentos em React, Node.js, consumo de APIs, autenticação com JWT, integração com MySQL, gerenciamento de estado, criação de gráficos e organização de projetos Full Stack.
