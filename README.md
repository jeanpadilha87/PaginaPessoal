# Portfólio pessoal - Jean Padilha

Site de portfólio acadêmico e profissional feito em HTML e CSS.

## Páginas principais

- `PaginaPessoal/index.html`: página inicial com apresentação, tecnologias, projetos, experiência, formação, certificações, currículo e contato.
- `PaginaPessoal/projetos.html`: lista de projetos em destaque.
- `PaginaPessoal/projeto-portfolio.html`: página individual do projeto Portfólio Pessoal.
- `PaginaPessoal/projeto-controle-academico.html`: página individual do projeto Sistema de Controle Acadêmico.
- `PaginaPessoal/projeto-implantacao.html`: página individual do projeto Implantação de Sistema.
- `PaginaPessoal/curriculo-jean-padilha.html`: currículo em formato HTML para download.
